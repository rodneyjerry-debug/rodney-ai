## 3. FIRST-HOUR PLAYBOOK (for max reach)

LinkedIn's algorithm weights the first 60–90 minutes heavily. A few small moves compound:

- **Pin a comment immediately** with one extra insight — e.g. *"For context: the Base case only gets Saudi banks to 38% non-interest share by 2030. GCC peer is 45%, DBS is 40%, JPMorgan is 48%. Nothing heroic about the number — it still leaves the sector behind the global best."*
- **Reply to every comment** in the first 2 hours. Questions get the full model shared in DM.
- **Avoid external links in the body** (LinkedIn suppresses them). If you must link, put it in the first comment.
- **Tag sparingly.** 1–2 senior banking voices max, and only if genuinely relevant. Don't spray.
- **Don't edit the post** in the first hour — edits reset reach.
